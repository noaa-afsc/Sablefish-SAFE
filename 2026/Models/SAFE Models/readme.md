# Final SAFE Model Runs

Model 26.2_FAA is the final author recommended model using a fleets-as-areas (FAA) structure, which dissaggregates the Longline Survey into regional fleets (BS, AI, GOA).

Model 26.1_1Reg is the updated version of the single region model.

Model 25.12 is the continuity model updated with data through 2026.

Model 26.2_FAA_3LLF+LLS_BS_Dome_DN is the SSC requested model that disaggregates the Longline Fishery (LLF) into 3 region fleets (matching the LLS structure) and allows for domed selectivity in the BS LLS and LLF based on a double normal selectivity curve.
